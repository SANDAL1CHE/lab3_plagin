# C++ AutoTest

Расширение для автоматического запуска сборки и тестов при Ctrl+Alt+T в VSC

---

## Что делает
* Отслеживает ввод хоткея
* Автоматически выполняет сборку через `cmake --build build`
* Запускает тесты через `ctest --test-dir build --output-on-failure`
* Выводит тесты в терминал VS Code

## Требования
Для работы расширения в системе должны быть установлены и доступны в `PATH`:
* **CMake**
* **Компилятор C++**

> **Примечание:** Должы быть `CMakeLists.txt` и `build`

## Использование
1. Открыть папку с проектом в VS Code
2. Открыть файл с кодом
3. Сохранить файл (`Ctrl + S`)
4. Нажать Ctrl+Alt+T
5. В терминале появятся результаты тестов
